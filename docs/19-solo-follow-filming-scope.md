# 自助式跟拍产品范围与候选筛选

用户明确要求：**“只考虑自助式，不考虑同伴 环境机位。”** 本轮目标仍是拍摄视角极佳、使用方便，载体不限定为风筝。此范围优先于前轮广泛调研中的场地服务与同伴互拍建议。

## 自助式的边界

一个人完成携带、展开、启动、拍摄、回收、收纳和取片。允许在停车时手动辅助起降、卷收和调整；不要求全自动，也不要求只有一台相机。

排除依靠同伴拍摄、摄影雪道、固定环境机位、环境索道摄影、提前沿途放置相机及依赖专用停栖设施的系统。即使由本人预放相机，也按环境机位排除。本人携带并自主随行的飞行相机、雪面设备，以及连接本人装备的系留系统仍可研究。

## 原有构想逐项筛选

编号对应[首轮调研](18-open-form-product-research-zh.md)的 28 个构想，以下是范围筛选，不是性能验证。

| 构想 | 当前处理 | 研究重点 |
|---|---|---|
| O01–O07 身体支撑与轻镜头 | 保留 | 折叠、卷尺、充气、可变刚度、背负弧、雪杖和分体镜头；检查全身视点与携带负担 |
| O08–O11 气动与浮力辅助 | 保留 | 轻翼、翼面卸载臂、自转旋翼、浮力；需要本人独立展开和收回 |
| O12–O15 自携飞行相机 | 保留 | 便携跟拍、短片起飞、全景成像、随身供电系留；关注启停与失跟找回 |
| O16 两台自有飞行器轮换 | 保留为远期假设 | 单人能否管理两套设备，增加的镜头是否值得 |
| O17 瞬时抛投镜头 | 仅作补充镜头 | 不满足连续跟拍主任务，还须独立完成回收 |
| O18–O19 雪面随行 | 保留 | 牵引小滑橇、自主雪面机器人；全程随用户移动且可自行携回 |
| O20–O25 场地与同伴机位 | 排除 | 不作为当前产品路线；原始资料仅留作技术参考 |
| O26 自动导演 | 限定后保留 | 只处理本人携带或自有跟随设备拍到的素材 |
| O27 有限新视点重建 | 限定后保留 | 仅用自携设备观测；缺失的真实视点不能由生成画面冒充 |
| O28 常驻相机加高光机位 | 限定后保留 | 高光镜头由本人摄影臂或自主随行设备提供，去除场地分支 |

O25 中的个人定位件可以作为自有跟拍设备的配件重新组合，但不因此保留“环境机位＋识别件”产品。范围内共有 18 个直接保留构想、3 个限定后保留构想、1 个补充镜头构想；6 个排除。

## 收窄后的比较重点

先比较两种个人产品：**可收拢摄影臂**与**自携短片飞行相机**。前者探索少操作的稳定随行视点，后者探索距离和方位更自由的高价值镜头。风筝、混合翼臂与雪面随行继续作为竞争分支，不预先判定胜负。自动导演是这些硬件可共享的能力。

每条路线都回答同一个问题：**增加的好镜头，是否值得本人承担全部携带、启停、故障恢复和取片操作？** 比较时记录可用画面、运动干扰、完整准备与回收时间、途中操作次数、失败后找回负担；不以他人代操作或预布场地来降低成绩中的工作量。

仿真候选筛选也采用此边界：只比较本人装备及其随行载体可获得的视点。用于工程观察的虚拟外部观察相机可以保留，但不能计入产品实际能够拍到的画面。

本次完成范围筛选，未增加性能证据或提升任何候选的成熟度。后续比较由 DES-030 承接；修订记录为 RES-031。
